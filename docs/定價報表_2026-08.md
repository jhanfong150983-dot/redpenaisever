## 一、對外定價

### 一句話版本

> 「AI 批改按考卷規模計價:一份 40~60 題的標準段考卷,批改定價 **NT$15**。
> 學生檢討單、學情分析、班級成績報表全部包含,不另收費;
> 家長學習報告每位學生加 NT$2。學校簽約量大另有優惠。」

### 價目表(對外唯一的一張表)

| 動作 | 定價 |
|---|---|
| AI 批改一份.一輪:20 題以內(小考) | NT$5 |
| 21~40 題 | NT$10 |
| **41~60 題(標準段考)** | **NT$15** |
| 61 題以上 | NT$20 |
| 家長學習報告(每位學生) | NT$2 |
| 學生訂正/自助批改(每次) | NT$1 |
| 學生檢討單 PDF / 學情分析 / 試題分析 / 成績報表 / 答案卷建置 | **免費** |

- 扣費單位=「動作」:一份考卷完成一輪批改扣一次,失敗不扣、重批照輪計費。
- 級距只看**題數**(答案卷題目數,建卷即定),與科目、頁數、照片或 PDF 無關。
- 合題(一格多小題)照主題數計,不展開小題。

### 學校端的三種講法

| 口徑 | 金額 | 參照感 |
|---|---|---|
| **每生每學期**(5 科 × 3 次段考+家長報告) | **~NT$200** | 一本參考書 |
| 每次段考全校(2,200 份) | ~NT$28,000 | 兩天代課鐘點 |
| 中小型國中(420 人)全學年全包 | ~NT$16 萬 | 一台互動白板 |

### 對讀卡機的定位(給銷售用)

- 學校只要選擇題分數 → 讀卡機較便宜,**不搶這個市場**。
- 我們接手的是讀卡機做不到的一半:**手寫題批改**+逐題分析+檢討單+家長報告。
- 對照組是教師人工:全校段考手寫題 ≈ 300+ 教師小時(≈ NT$12 萬代課鐘點);我們收 ~2.8 萬、一晚出完(實測 10 份 2.5 分鐘)。

### 負擔性退階方案(銷售彈性,由淺入深)

1. **單科試辦**:一次段考一科 ~NT$5,000
2. **只批非選**:選擇題照舊讀卡、手寫題給我們(答案卷模式原生支援)
3. **段考限定**:平時考不用,一學期三筆固定支出
