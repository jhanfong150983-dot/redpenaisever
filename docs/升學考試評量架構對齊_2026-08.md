# 三大升學考試的評量架構:規格盤點與系統對齊設計

> 2026-08-07。目的:讓 RedPen AI 的**答案卷分析**與**家長報告**使用與官方考試
> **同一套語言與代碼**,而不是自創分類。
> 信心:✅已取得官方文件原文、◐部分取得需補、⚠️各縣市不一致。

---

## 摘要:三個學段各自能對齊到什麼

| 學段 | 對標考試 | 可用的**題目標籤**體系 | 可用的**成績分級**語言 |
|---|---|---|---|
| 國小 | 縣市學生學習能力檢測 / 各縣市學力檢測 | ✅**評量向度**(各科各年級明列) | ◐等級成績(113 年起新增,3 級) |
| 國中 | 國中教育會考 | ◐命題依據=108 課綱學習表現/學習內容 | ✅**精熟A/基礎B/待加強C + ++/+ 標示**、寫作六級分 |
| 高中 | 學科能力測驗 | ✅**測驗目標代碼**(國文 A1-A6/B1-B5、社會 H/G/C/S、自然 1a-5c…) | ✅級分制、五標 |

**最有價值的三個發現**:
1. **學測有現成的題目分類代碼**,而且是官方公告、逐題可標(下面第三節全列)
2. **會考有現成的等級描述文字**,可直接當家長報告的分級用語(第二節)
3. **國小檢測的「評量向度」與 108 課綱主題軸同構**,可用同一組骨幹涵蓋國小到國中

## 一、國小:縣市學生學習能力檢測(國立臺中教育大學主辦)✅

跨縣市共用的檢測,國小 1~6 年級、國中 7~8 年級,科目:國語文、數學、英語文、自然(115 年起)。
**每個年級每個科目都有公告的「評量向度說明與試題分布」PDF**,可逐年下載
(`saaassessment.ntcu.edu.tw/AssessmentFrame`,108~115 年度齊全)。

### 五年級國語文 評量向度(原文)✅
| 向度 | 定義 |
|---|---|
| 形音知識 | 能辨認字形(含形近字、同音字)、字音(含形近字音、多音字音) |
| 字詞知識 | 能直接辨認詞語(含四字詞、成語)涵義 |
| 語法知識 | 能辨認語法(含標點、詞類、詞彙結構、句型(含關聯複句)、句型結構、病句等) |
| 修辭知識 | 能辨認修辭 |
| 章法知識 | 能辨認文章組織方式 |
| 文體知識 | 能辨認文本體裁 |
| 字詞理解 | 能運用上下文理解字詞涵義、推論指代詞 |
| 句子理解 | 能理解、推論語句涵義 |
| 段落理解 | 能推論段落內容、掌握主旨 |
| 篇章理解 | 能直接理解篇章訊息、推論理解篇章內容、詮釋整合篇章主旨或寫作手法 |

> ⭐ 這十個向度**幾乎就是我們國語卷的天然分類**(國字注音→形音知識、
> 語詞成語→字詞知識、閱讀測驗→段落/篇章理解)。

### 五年級數學 評量向度(原文)✅
**數與計算 / 量與實測 / 空間與形狀 / 關係 / 資料與不確定性** —— 每個向度下明列該年級的具體單元
(如「數與計算:等值分數、十進位位值系統、多步驟應用問題、公因數和公倍數…」)。

### 八年級數學 評量向度(原文)✅
**數與量 / 空間與形狀與坐標幾何 / 代數與函數 / 資料與不確定性**

> ⭐ 這組向度**與 108 課綱數學領域主題軸同構**(N 數與量、S 空間與形狀、G 坐標幾何、
> A 代數、R 關係、F 函數、D 資料與不確定性)→ **國小到國中可用同一組骨幹**。

### 五年級英語文 評量向度(原文)✅
- **聽力**:語音聽辨 / 辭彙聽辨 / 教室生活辭句理解與回應 / 文化節慶理解
- **閱讀**:字詞辨識 / 句子理解 / 短文與對話理解 / 文化節慶理解

### ⚠️ 注意事項
- **各縣市不一致**:臺北市另有自己的「國民小學基本學力檢測」(五年級、國語數學英語,
  只公布全市平均與通過率、不公布個人成績);其他縣市有的用臺中教大這套、有的自辦
- **成績回饋**:學校可登入下載(保存三年),結果會匯入教育部因材網
- 113 年起新增「等級成績」呈現(供參考用)◐ 需再查各級定義

## 二、國中:國中教育會考 ✅

### 成績分級(可直接當家長報告用語)✅
三等級:**精熟(A)/基礎(B)/待加強(C)**;精熟與基礎另加標示 **「++」=該等級前 25%、
「+」=前 26%~50%**。國文、社會、自然依**答對題數**分級;英文、數學以**加權分數**分級。

### 各科能力等級描述(官方原文摘要)✅

| 科目 | 精熟 | 基礎 | 待加強 |
|---|---|---|---|
| 國文 | 能具備與教材相關的語文知識,能**深入的**理解、評鑑各類文本 | **大致能**具備…大致能理解、評鑑各類文本 | **僅能**具備部分…僅能有限的理解 |
| 英語閱讀 | 能理解所學字詞的**常見**語意、常見句型結構,能指出主旨 | 能理解**基本**語意、基本句型結構,能提取明確訊息 | 僅能理解**少數**字詞的基本語意 |
| 英語聽力 | (目前僅分兩級) | 能聽懂與個人日常生活相關的簡短語句、問答 | 僅能有限地聽懂少數簡短語句 |
| 數學 | 能**分析複雜、不明顯**的數學訊息,並發展解題策略 | 理解**基本**數學概念,能操作算則或程序 | 僅認識部分基本概念,僅能操作部分算則 |
| 社會 | 能**廣泛**認識學習內容,運用**多元**知識探究 | 能**大致**認識,運用**基礎**知識探究 | 能**約略**認識,並能覺察相關訊息 |
| 自然 | 能**融會貫通**,運用探究能力解決**多層次**思考問題 | 能知道及理解,運用探究能力解決**基本**問題 | 能**部分**知道及理解 |

**寫作測驗六級分**:六/五級分=精熟、四級分=基礎、三/二/一級分=待加強、零級分(離題或空白)。

> ⭐ 這組描述的句式很規律(**深入/大致/僅能**、**廣泛/大致/約略**、**複雜/基本/部分**)——
> 家長報告可以直接沿用這套修辭,家長一看就知道對應到會考的哪一級。

### 題數與時間(115 年)◐
國文 38~46 題/70 分;數學 23~28 選擇+2~3 非選/80 分;社會 50~60 題/70 分;
自然 45~55 題/70 分;英語閱讀 40~45 題/60 分;英語聽力 20~30 題/25 分;寫作 1 題/50 分。

### 命題依據 ◐
以 108 課綱的**學習表現**與**學習內容**為命題依據,採標準參照計分。
題型結構:**學科基本素養題**(重要概念)+**生活實踐題**(真實情境)。
⚠️ 會考**沒有像學測那樣公告逐題可標的代碼體系**;要做題目標籤,得回到 108 課綱的學習表現代碼。

## 三、高中:學科能力測驗(大考中心)✅ —— 代碼體系最完整

### 共同測驗目標(總說明原文)✅
以 108 課綱「學習內容」與「學習表現」為依據,四個方向:
1. 測驗考生所具有的**基本學科能力**
2. 測驗考生為銜接大學教育而所具有的**基本學科知能**
3. 測驗考生能於不同情境中**整合運用**基本學科知識、解決問題的能力
4. 測驗考生的**閱讀理解、圖表判讀、證據運用、邏輯推論、分析評價、表達說明**等能力

### 各科測驗目標代碼(可逐題標記)✅

**國文(國綜)** —— 兩面向、11 個代碼
- **一、國語文知識的認知與應用**:`A1` 字形字音字義 / `A2` 語詞成語 / `A3` 語法 /
  `A4` 表現手法與表述方式 / `A5` 文學作家作品體類流派 / `A6` 學術思想與文化
- **二、文本的理解與探究**:`B1` 訊息的檢索與擷取 / `B2` 文意的理解比較分析統整 /
  `B3` 內容的延伸與反思 / `B4` 形式的推究與分析 / `B5` 結合文學文化知識的詮釋與鑑賞

**社會** —— 四大項、26 個代碼(H=歷史、G=地理、C=公民、S=跨科)
- 一、掌握基礎知識與技能以覺察說明:`H1`~`H2`、`G1`~`G3`、`C1`~`C2`
- 二、運用知識技能方法以分析詮釋:`H3`~`H6`、`G4`~`G6`、`C3`~`C5`
- 三、判斷、反思與評鑑:`H7`~`H9`、`G7`~`G9`、`C6`~`C7`
- 四、整合學科方法進行探究:`S1`~`S5`

**自然** —— 五大項、18 個細項代碼
- `1a`~`1d` 基本知識與概念(認識理解名詞定義/現象規則學說定律/各分科進展/學科間共通原理)
- `2a`~`2c` 資料和圖表的理解(理解意義/歸納特性規則關係/作分類比較排序歸類)
- `3a`~`3d` 知識的應用(應用資料解題/以定律模型解釋現象/由觀察或前導結果作合理假設/探究過程與實驗架構)
- `4a`~`4d` 分析與歸納(說明論證歸納原理/發現問題因果/整理不同觀點異同/進行系統性分析)
- `5a`~`5c` 整合與表達(表達與說明/綜合科學見解提出解釋或建議/評論科學對自然環境或人類社會的影響)

**數學** —— 六大測驗目標
概念性知識 / 程序性知識 / 閱讀與表達能力 / 連結能力 / 推理能力 / 解決問題能力

**英文** —— 七項測驗目標
實詞詞彙構詞語意搭配 / 上下文詞彙與語法 / 篇章段落實詞運用 / 篇章組織架構與文意脈絡 /
綜合運用(理解、擷取、分析比較推理) / 中譯英 / 依提示寫出一致連貫短文

### 題型與配分比例(可對照我們的試題分析)✅
| 考科 | 配分結構 |
|---|---|
| 國文 | 國綜 100 分 + 國寫 50 分,**各占 50%**(原始得分=國綜×0.5+國寫) |
| 數學 A/B | 第壹部分(單選/多選/選填)**80~85%**;第貳部分混合題型 **15~20%** |
| 社會 | 歷史/地理/公民**三科均衡**;全卷**非選擇題型占 20~30%** |
| 自然 | 物化生地**四科比例相當**;第壹部分選擇題 **70~80%**、第貳部分混合題 **20~30%** |
| 英文 | 選擇題型 + 混合題型 + 非選(中譯英、英文作文) |

**測驗時間**:國文(一)90 分、國文(二)90 分、英文 100 分、數學 A/B 各 100 分、社會 110 分、自然 110 分。

**混合題型定義**(111 學年度起新增):同時包含選擇題、選填題與非選擇題的**題組**形式,
搭配「卷卡合一」A3 新式答題卷。

## 四、對 RedPen AI 的對齊設計

### 現況盤點(已存在的東西)
- `assignment.conceptTags`:{questionId → {code, label}} —— 答案卷抽取時 AI 標記的 **108 課綱概念代碼**(如 N-4-12)
- `answer_key.questions[].analysis`:{`topic`, `knowledgePoints[]`, `code`, `ability`, `cnaArea`, `note`}
  —— 三層歸類(課綱指標→白話主題→知識點),`ability`/`cnaArea` 目前是選填自由文字
- 批改時 `conceptTags` 會凍結進 submission

→ **骨幹已經有了(108 課綱代碼),缺的是「考試框架」這一層。**

### 建議:加第二個標籤軸「考試向度」

```
題目
 ├─ 內容軸(已有):108 課綱概念代碼 → topic → knowledgePoints   ← 「考什麼單元」
 └─ 能力軸(新增):examFramework + examDimension               ← 「考什麼能力」
```

`analysis.examDimension` 依學段自動採用不同體系:

| 學段 | examFramework | examDimension 值域 |
|---|---|---|
| 國小 | `saa`(縣市學力檢測) | 國語文十向度 / 數學五向度 / 英語聽讀各四向度 |
| 國中 | `cap`(會考) | 108 課綱學習表現代碼(會考無自有代碼)+ 題型標記(基本素養題/生活實踐題) |
| 高中 | `gsat`(學測) | 國文 A1-A6/B1-B5、社會 H/G/C/S、自然 1a-5c、數學六目標、英文七目標 |

**實作成本低**:答案卷抽取已經在跑 AI 標記(`ANSWER_KEY_TAG_CONCEPTS` 路由),
把該學段的向度清單一起餵進 prompt 讓它多標一個欄位即可,不需新增 AI 呼叫。

### 三個立即可做的產品升級

**1. 試題分析報告 → 加「向度雷達圖」**
現在按題呈現;加上按 examDimension 彙總的答對率,老師一眼看到
「這次段考『篇章理解』全班只有 42%,但『形音知識』有 88%」。
⭐ 這是讀卡機和卷卡合一**做不到**的(它們沒有手寫題的向度資料)。

**2. 家長報告 → 用官方分級語言**
把現有的白話診斷,換成會考的三級修辭:
> 「小明在數學的表現接近**基礎**等級:能理解基本的數學概念、能操作算則或程序;
> 但在**分析複雜、不明顯的數學訊息並發展解題策略**(精熟等級)還需加強。」

家長聽得懂,而且**與三年後的會考成績單同一套語言** —— 這是很強的說服力。
⚠️ 用語須加註「以會考能力等級描述為參照,非官方檢測結果」,避免誤導。

**3. 學情報告 → 加「對標升學考」段落**
以本次段考的向度覆蓋率,對照該學段考試的配分比例
(如學測社會非選 20~30%、自然混合題 20~30%),提示老師
「本卷非選僅占 8%,與學測結構落差較大」。⭐ 這是命題品質的回饋,老師會很有感。
